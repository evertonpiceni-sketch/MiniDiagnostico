# Auditoria PDF — 14/09/2026

Correção isolada da camada de exibição dos resultados antes de qualquer merge em produção.

## Problema confirmado

`src/result-enhancer.ts` renderizava somente `doc.getPage(1)`. Portanto, qualquer PDF definitivo com três páginas teria apenas a primeira página exibida no resultado online.

## Regra desta correção

- não altera textos canônicos;
- não altera perguntas, desempates, pagamento ou autenticação;
- não altera os arquivos PDF existentes;
- renderiza todas as páginas presentes no PDF;
- mantém WhatsApp e download como links HTML reais, abaixo do documento, para funcionamento móvel confiável;
- impressão preserva uma página A4 por página do PDF.

## Bloqueio para merge

O merge só deve ocorrer depois que os três PDFs definitivos estiverem efetivamente presentes no GitHub e forem auditados visualmente e textualmente. O relatório que citou o commit `90146dd` não pôde ser confirmado no repositório no momento desta auditoria.
